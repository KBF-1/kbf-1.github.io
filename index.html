🚀 What is DevProxy?

DevProxy is a powerful yet simple security tool that works quietly in the background while you develop. It acts as a passive security proxy—meaning it watches the web traffic between your browser and your development server, checking for common security issues in real-time.

The best part? It's designed to be completely decoupled and asynchronous. This means it never gets in your way, adds no noticeable delay, and you don't need to change a single line of code to use it.

Whether you're building a website, a mobile app API, or just testing your localhost, DevProxy helps you catch vulnerabilities early—before they reach production.

✨ Key Features

🔍 Real-Time Traffic Inspection

Automatically analyzes every HTTP/HTTPS request and response for common security vulnerabilities, including JWT issues, exposed headers, and suspicious patterns.

⚡ Zero-Latency Design

Unlike traditional proxies, DevProxy works asynchronously—it never blocks or delays your traffic. You won't even know it's running.

🔒 MITM (Man-In-The-Middle) Support

Inspects both HTTP and HTTPS traffic with full support for TLS interception, so you can analyze secure connections too.

📝 OpenAPI Integration

Understands OpenAPI specs and provides intelligent insights based on your API definitions, making vulnerability detection more accurate.

🧩 Lightweight & Open Source

Built with Go for maximum performance. Free to use, modify, and contribute to under the MIT license.

🛠️ Developer Friendly

Perfect for chaos engineering and testing environments. Set it up once and let it protect every project you work on.

🤔 Frequently Asked Questions

Is DevProxy free to use?

Yes! DevProxy is completely free and open-source. It's released under the MIT License, which means you can use it for personal and commercial projects without any cost.

Will DevProxy slow down my computer?

No. DevProxy is designed for zero-latency performance. It runs asynchronously, meaning it processes traffic without blocking or delaying your requests. You won't notice any difference in speed.

Do I need to configure my browser or server?

No configuration needed. DevProxy automatically intercepts and inspects traffic. However, for advanced use cases like inspecting HTTPS traffic, you might need to trust its certificate. But for basic HTTP development, everything works out of the box.

What kinds of vulnerabilities does it detect?

DevProxy looks for common issues like missing security headers, exposed JWT tokens, SQL injection patterns, cross-site scripting (XSS) indicators, and other suspicious activity in your traffic.
